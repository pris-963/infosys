1. OBJECTIVE OF MILESTONE 2: AI THREAT DETECTION & EXPLAINABLE AI (XAI)
--------------------------------------------------------------------------------
Evolving the dashboard from simple security monitoring into an AI-driven threat
response interface. Displays model prediction classifications, confidence metrics,
and attributes underlying rules contribution without LLM complexity.

Note: Since this repository is frontend-scoped, focus is strictly on client UI.

--------------------------------------------------------------------------------
2. FRONTEND TASKS SPECIFICATIONS
--------------------------------------------------------------------------------
- Card Counters:
  * Total Events, Anomalies Detected, Normal Events, High-Risk Events, Critical Threats.
- Threat Detection Table Columns:
  * Event ID, Event Type, Prediction, Confidence, Severity, Timestamp.
- Anomaly Distribution Doughnut Chart:
  * Classes: Normal, Suspicious, Critical.
- Anomaly Trend Line Graph:
  * Time (X-axis) vs. Number of detected anomalies (Y-axis).
- Threat Type Bar Chart:
  * Categories: Brute Force, Malware, Phishing, SQL Injection, Privilege Escalation.
- Event Investigation Drilldown:
  * Event Details: Source IP, Destination IP, User, Event Type, Timestamp, Asset, Severity, CVSS.
  * AI Analysis: Prediction (Normal/Suspicious/Critical), Confidence (Percentage), and Reason text.
  * Explainable AI checklist showing checked flags:
    ✓ Failed login attempts > threshold
    ✓ Unusual login time
    ✓ Impossible travel detected
    ✓ High event frequency
